# SHARED_LEARNING.md — Shared Learning

*What one agent learns becomes shared knowledge, by a reviewed change.*

---

Every lesson an agent writes to its own memory also lands in the corpus, in a generalized, anonymized form, by a reviewed change.

- **Generalized** keeps the rule and its why, and drops the incident.
- **Anonymized** drops person names, agent names, hostnames, home paths, emails, and private repository or issue numbers.

The change is built and reviewed like any other. A change that lands is picked up by the retrieval index as a separate act after it merges — nothing in the change itself touches that index.

## Why

What the team learns is shared knowledge any agent can recall, not private to one machine. A lesson that stays in one agent's memory helps only that agent; the same lesson in the corpus helps every agent from then on.
